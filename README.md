# CRED_APPLICATION

CRED-like Credit Card Management, Statement Billing & Payment Ledger Web Application built with PHP, MySQL PDO, Smarty v5, Bootstrap 5, and Vanilla CSS.

## Features
- **User Authentication**: Secure Registration, Login, and Session-based Access Control.
- **Card Management**: Add, View, and Manage Credit Cards with dynamic card styling, Credit Limits, Available Credit calculation, and Utilization metrics.
- **Bill Statement System**: Statement generation, Due Dates, and Minimum Due calculations.
- **Payment & Immutable Ledger**: Persistent payment transaction records, payment methods, receipts, and cashback rewards.
- **Payment History & Transaction Logs**: Dedicated searchable and filterable transaction history ledger.
- **Payment Analytics & CRED Rewards**: Monthly spend breakdown, rewards tracking, and analytics dashboard.

## Tech Stack
- **Backend**: PHP 8.2+, OOP, PDO Prepared Statements, MVC Pattern
- **Database**: MySQL (`cred_db`)
- **Template Engine**: Smarty v5
- **Frontend**: Bootstrap 5, Bootstrap Icons, Vanilla CSS
